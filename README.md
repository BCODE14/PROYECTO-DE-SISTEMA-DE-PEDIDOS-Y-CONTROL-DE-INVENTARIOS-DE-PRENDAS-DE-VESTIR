# PROYECTO-DE-SISTEMA-DE-PEDIDOS-Y-CONTROL-DE-INVENTARIOS-DE-PRENDAS-DE-VESTIR
Desarrollo de un sistema de pedidos para prendas de vestir y control de inventario para una microempresa, dedicada a la confección de trajes utilizando Java y Mysql para el almacenamiento de datos(BBDD).  Cuenta con los siguientes módulos: login, Nuevo Pedido, Pedidos, Clientes, Moldes, Inventarios, Calendarios, Reportes.
